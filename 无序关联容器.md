# 无序关联容器

## unordered_map

## unordered_map成员函数

### 构造函数

```c++
// 默认构造函数：空映射
std::unordered_map<std::string, std::string> m1;

// 列表构造函数
std::unordered_map<int, std::string> m2 =
{
	{1, "foo"},
	{3, "bar"},
	{2, "baz"}
};

// 复制构造函数
std::unordered_map<int, std::string> m3 = m2;
```

### 赋值函数

`````c++
std::unordered_map<int, int> x{{1,1}, {2,2}, {3,3}}, y;
y = x;
`````

### 迭代器

`````c++
unordered_map<string,int>map{
        {"sunrise",100},
        {"zhangsan",100},
        {"lisi",90}
};
for(auto iter = map.begin();iter!=map.end();iter++){
    std:cout<<iter->first<<"  score="<<iter->second<<endl;
}

输出:
/*
lisi  score=90
zhangsan  score=100
sunrise  score=100
*/
`````

### 容量

#### map.size()

#### map.empty()

`````c++
map.size() //返回int,键值对数量
map.empty //返回bool值,如果为空返回true
`````

### 修改器

#### map.insert()

```c++
unordered_map<string,int>map{
        {"sunrise",100},
        {"zhangsan",100},
        {"lisi",90}
};
std::cout<<map.insert({"sunrise",100}).second; //插入失败返回false
```

#### map.erase()

**iterator erase( iterator pos );**

```c++
unordered_map<string,int>map{
        {"sunrise",100},
        {"zhangsan",43},
        {"lisi",90}
    };
auto iter=map.begin();
std::cout<<map.erase(iter)->second;

//输出43
```

#### map.merge()

将map2元素合并到map1中

```	c++
    unordered_map<string,int>map{
        {"sunrise",100},
        {"zhangsan",43},
        {"lisi",90}
    };

    unordered_map<string,int>map2{
        {"sunrise",19},
        {"wangwu",43}
    };
    map.merge(map2);
    std::cout<<"========map:========"<<endl;
    for(auto iter=map.begin();iter!=map.end();iter++){
        std::cout<<iter->first<<"  "<<iter->second<<endl;
    }
    std::cout<<"========map2:========"<<endl;
    for(auto iter=map2.begin();iter!=map2.end();iter++){
        std::cout<<iter->first<<"  "<<iter->second<<endl;
    }
/*输出结果
========map:========
wangwu  43
lisi  90
zhangsan  43
sunrise  100
========map2:========
sunrise  19
*/
```

### 查找

#### map.at(key)

返回 值的引用 **可作为左值**

不存在抛出异常

```c++
    unordered_map<string,int>map{
        {"sunrise",100},
        {"zhangsan",43},
        {"lisi",90}
    };

    std::cout<<map.at("sunrise")<<endl;	//输出100
    std::cout<<map.at("rise")<<endl;	//抛出异常
    map.at("sunrise") = 30;		//可作为左值
    std::cout<<map.at("sunrise")<<endl;
```

#### map[key]

不存在自动插入

不存在拥有键 key 的元素时 返回到新元素被映射值的引用。

否则返回 指代其键等价于 key 的既存元素的被映射值的引用

`````c++
unordered_map<string,int>map{
    {"sunrise",100},
    {"zhangsan",43},
    {"lisi",90}
};
std::cout<<map["wangwu"]<<endl; //输出默认值0
map["wangwu"]=42;  
std::cout<<map.at("wangwu")<<endl;//输出42
`````

#### map.find(key)

返回map中拥有key的元素

iterator find( const Key& key );

`````c++
    std::cout<<map.find("sunrise")->second; //输出100
`````

map.contains(key)

```c++
    std::cout<<map.contains("sunrise");   //1
```
